Dice inside the computer

Würfel im Computer

Games need dice. Where does the spider stand? Which sword does the chest hold? Is this cube a meadow or a lake?

Spiele brauchen Würfel. Wo steht die Spinne? Welches Schwert liegt in der Truhe? Ist dieser Würfel eine Wiese oder ein See?

But a computer is an exact machine. It does the same thing every time. It cannot really roll a die!

Aber ein Computer ist eine ganz genaue Maschine. Er macht jedes Mal dasselbe. Er kann gar nicht richtig würfeln!

So it uses a trick. It takes a number and puts it through a scrambling formula. Out comes a new number that looks random. Put that one through the formula again, and you get the next one. And so on, forever.

Darum benutzt er einen Trick. Er nimmt eine Zahl und steckt sie in eine Durcheinander-Formel. Heraus kommt eine neue Zahl, die zufällig aussieht. Steck die wieder in die Formel, und du bekommst die nächste. Und so weiter, für immer.

The very first number is called the seed. Everything grows from the seed, like a plant.

Die allererste Zahl heißt Seed (englisch für Samenkorn). Alles wächst aus dem Seed, wie eine Pflanze.

The big secret

Das große Geheimnis

The same seed always gives exactly the same numbers, in the same order.

Derselbe Seed gibt immer genau dieselben Zahlen, in derselben Reihenfolge.

So the same seed gives the same world: the same hills, the same rivers, the same monsters in the same places.

Also gibt derselbe Seed dieselbe Welt: dieselben Hügel, dieselben Flüsse, dieselben Monster an denselben Stellen.

Try it in the game: ?seed=123 and then ?seed=124. Visit them twice. The town is always there, but the cubes behind it change with the seed.

Probier es im Spiel aus: ?seed=123 und dann ?seed=124. Besuch jede zweimal. Die Stadt ist immer da, aber die Würfel dahinter ändern sich mit dem Seed.

Try it: same seed, same dice

Probier es: gleicher Seed, gleiche Würfel

Seed A and seed B start the same. Roll a few times: the seeded rows are the same every time. The bottom row uses the browser's own Math.random(), which picks a new secret seed itself, so it changes.

Seed A und Seed B fangen gleich an. Würfel ein paarmal: Die Reihen mit Seed sind jedes Mal gleich. Die unterste Reihe benutzt das eigene Math.random() des Browsers, das sich selbst einen geheimen Seed ausdenkt. Darum ändert sie sich.

This uses the game's real dice, the function mulberry32 from src/core/util.js.

Hier laufen die echten Würfel des Spiels, die Funktion mulberry32 aus src/core/util.js.

Why "not really random" is great

Warum "nicht wirklich zufällig" super ist

Hunting bugs

Fehlerjagd

If a bridge is broken in world 123, a developer can open world 123 and see the exact same broken bridge. Fixing a bug you cannot see again is almost impossible.

Wenn in Welt 123 eine Brücke kaputt ist, kann ein Entwickler Welt 123 öffnen und genau dieselbe kaputte Brücke sehen. Einen Fehler zu reparieren, den man nicht wiederfinden kann, ist fast unmöglich.

Tests

The game's tests build hundreds of worlds with fixed seeds and check them. Because the seeds are fixed, a test that passes today passes tomorrow, unless the code changed.

Die Tests des Spiels bauen Hunderte Welten mit festen Seeds und prüfen sie. Weil die Seeds fest sind, besteht ein Test, der heute besteht, auch morgen, außer der Code hat sich geändert.

No cheating

Kein Schummeln

What a monster drops is decided by the world seed and the monster's name. If you die and the monster comes back, it drops the same thing again. Dying on purpose does not give you better loot!

Was ein Monster fallen lässt, hängt vom Welt-Seed und vom Namen des Monsters ab. Wenn du stirbst und das Monster wiederkommt, lässt es dasselbe wieder fallen. Absichtlich sterben bringt dir keine bessere Beute!

Every cube gets its own dice

Jeder Würfel bekommt eigene Würfel

If the whole world used one row of dice, building cube A first or cube B first would change both of them. Messy!

Würde die ganze Welt eine einzige Würfelreihe benutzen, dann würde es beide verändern, ob zuerst Würfel A oder Würfel B gebaut wird. Chaos!

So every cube makes its own seed: it mixes the world seed with its own name, like "2,-1,0" (that is: 2 east, depth 1, 0 south).

Darum macht sich jeder Würfel seinen eigenen Seed: Er mischt den Welt-Seed mit seinem eigenen Namen, zum Beispiel "2,-1,0" (also: 2 nach Osten, Tiefe 1, 0 nach Süden).

The mixer is called a hash: a formula that turns anything into a number that looks random. A tiny change in the name gives a totally different number.

Der Mixer heißt Hash: eine Formel, die alles in eine Zahl verwandelt, die zufällig aussieht. Eine winzige Änderung im Namen gibt eine völlig andere Zahl.

The walls between cubes, the monsters, the loot and the decorations get their own streams too.

Die Wände zwischen Würfeln, die Monster, die Beute und die Deko bekommen auch eigene Zahlenreihen.

A bag of marbles

Ein Beutel voller Murmeln

Not everything should be equally likely. A rare sword should be rare! So the game uses weights: imagine a bag with 28 cream marbles (Vanilla), 14 beige (Unremarkable), 22 green (Decent) and 8 blue (Unusual). Grab one without looking.

Nicht alles soll gleich wahrscheinlich sein. Ein seltenes Schwert soll selten sein! Darum benutzt das Spiel Gewichte: Stell dir einen Beutel vor mit 28 cremefarbenen Murmeln (Vanilla), 14 beigen (Unremarkable), 22 grünen (Decent) und 8 blauen (Unusual). Greif blind hinein.

The game uses this for almost every choice: which kind of cube, which archetype, which monster, which sword, which name.

Das Spiel benutzt das für fast jede Wahl: welche Art Würfel, welcher Archetyp, welches Monster, welches Schwert, welcher Name.
