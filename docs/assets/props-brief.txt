PROPS FOR CUBE CRAWLER - what the game needs from Blender
=========================================================

Context
-------
The game (this repo) is a world of 16x16-cell cubes stacked into 20 depths.
Every depth has a theme (palette + fluids + lighting); see src/themes/index.js and
caves.js for the exact colours. The terrain is LOW-POLY and FLAT-SHADED, coloured with
vertex colours (gradients by height, darker cliff strata, a lighter lip on cliff tops). The
character and the spider are smooth "clay" models (blender/character.py, spider.py).
The props should sit between the two: chunky, simple, slightly irregular shapes with FLAT
shading and few polygons, so they read as part of the terrain. No textures.

We want decoration props the generator can scatter per theme (instanced, many per cube).

Deliverable
-----------
* blender/props.py   - a script in the same style as figure.py / spider.py (module docstring
                        with usage, constants at the top, build functions, headless usage:
                        Blender -b --python blender/props.py -- assets/props)
* assets/props/      - one glb per prop set (<set>.glb), every prop its own top-level mesh object
                        (was: ONE assets/props.glb; split so the game loads only the sets it shows).

Units, axes, pivots
-------------------
* 1 Blender unit = 1 game cell. A terrain level is 0.5 high. The character is ~1.1 tall,
  the spider ~0.6 tall and ~0.8 across. Use these for scale.
* Export with Y up (export_yup=True, like character.py). In Blender: Z up, model "standing" on
  the XY plane.
* Pivot (object origin) depends on how the prop attaches (see "attach" below):
    ground : origin at the centre of the base, base at z = 0 (sits on the floor top)
    ceiling: origin at the attachment point, the prop hangs DOWN from z = 0 (slab undersides)
    wall   : origin on the wall plane at the attachment point; the prop sticks out along +Y
             (Blender) and its back is flat at y = 0
* Keep the footprint of ground props inside one cell (radius <= 0.45) unless noted.
* Apply all transforms before export (scale 1, rotation 0). No modifiers left unapplied.

Mesh / material rules
---------------------
* 40-400 triangles per prop (trees up to ~600). They get instanced dozens of times per cube.
* Flat shading (no smooth normals), no UVs needed.
* Colour: vertex colours (COLOR_0, linear) are preferred, one mesh per prop. Alternatively a
  handful of plain materials (base colour only). Glowing parts: a separate material with an
  emissive colour (strength 1-3); name that material "<prop>_glow".
* ROCKS AND STONE PROPS IN NEUTRAL GREYS (light-to-dark), so the game can tint them per theme.
  Everything else can be coloured for its theme (palette hints below).
* Small irregularities (jittered vertices, uneven facets) are good; perfect primitives look out
  of place next to the terrain.

Names and metadata
------------------
* Object name: <theme>_<prop>_<variant>, lower case, e.g. meadow_tree_a, caves_crystal_b,
  any_rock_c ("any" = used by every theme, tinted by the game).
* 2-3 variants per prop (the game also randomises yaw and scales by +-15%).
* Put custom properties on each object (exported as glTF extras, export_extras=True):
    attach   : "ground" | "ceiling" | "wall"
    radius   : footprint radius in cells (for spacing and collision)
    blocking : true if the character should bump into it (trunks, boulders, columns)
    light    : optional "#rrggbb" for props that should glow / light the area
    intensity: optional light strength hint (1 = small glow, 3 = lamp)
    sway     : optional 0..1, how much it should sway in wind (the game animates it)

Props by theme (priority 1 first in each list; do priority 1 across all themes first)
----------------------------------------------------------------------------------------
any (all themes, NEUTRAL GREY, tinted in game)
  P1 rock (small, knee high, 3 variants), boulder (blocking, radius 0.4, 2 variants),
     pebbles (flat cluster, decal-like, 2 variants)
  P2 stalagmite (ground, 0.5-1.2 tall), stalactite (ceiling, hangs 0.4-1.0)

meadow (depths 0-2, sunny floating islands; grass greens #4c8a3c-#a3b26a, bark #6e4420)
  P1 tree_round (blocking, ~2.2 tall, lollipop/blobby crown), tree_tall (~3 tall, narrow),
     bush (0.5 tall), grass_tuft (tiny, 3-5 blades, sway 0.6), flowers (small clusters,
     white/yellow/pink, sway 0.4)
  P2 stump, fallen_log (radius 0.45, lying), mushroom_small (red cap)

peaks (depth 3, snow; whites #e6eef1, rock greys, dark pine green #2f4a3a)
  P1 pine_snow (blocking, ~2.5 tall, snow on the branches), pine_small, snow_rock (grey rock
     with a white cap - coloured, NOT tinted), ice_shard (pale blue, translucent look via
     colour only)
  P2 snowman-sized snow lump, frozen bush

badlands (depth 4, dusk desert; sand #d3a466, red rock #80502f)
  P1 cactus (blocking, ~1.4 tall, arms), dead_tree (bare twisted branches, ~2 tall),
     dry_shrub (tumbleweed-like, sway 0.3), bleached_skull (cow-like, small)
  P2 sandstone_pillar (hoodoo, blocking, 1.5-2.5 tall, layered bands)

roots (depths 5-6, earthy caves; dirt #5e4c35, moss #4a5a2a)
  P1 hanging_roots (ceiling, 0.6-1.5 long, tangled strands, sway 0.3),
     root_arch (ground, a thick root looping out of the ground, radius 0.45),
     mushroom_cluster (small brown/white caps)
  P2 moss_rock (rock with a moss cap, coloured)

frozen (depths 7-8, ice caves; ice blues #82a6b8-#d8ecf2)
  P1 ice_crystal (ground, tall faceted shard cluster, light #9fd8ff intensity 1),
     icicles (ceiling, a row of 3-6, 0.3-0.9 long), frozen_pool_rim (flat ring of ice chunks)
  P2 frozen_spider_cocoon (an icy lump for flavour)

swamp (depths 9-10, fungal; moss greens #4b5a2e, acid green #7dff3a)
  P1 glow_mushroom (ground, big cap 0.6-1.2 tall, cap underside glows, light #8fff7a
     intensity 1.5), mushroom_shelf (wall, bracket fungus), reeds (sway 0.5),
     spore_pod (round bulb, glowing spots)
  P2 slime_puddle (flat), vines (ceiling, sway 0.4)

nests (depths 11-12, spider nests; dark purplish greys #4a444a-#6e6874, web white #e8e4ea)
  P1 cobweb_corner (wall or ground, a flat triangular web spanning ~1 cell, semi-white),
     egg_sac (cluster of pale eggs, 0.4 tall), wrapped_victim (cocoon hanging, ceiling)
  P2 web_strands (ceiling, loose hanging threads, sway 0.3), bone_pile

mines (depths 13-14, crystal mines; slate #5a5a64, crystal #7a8aa8 / cyan / violet)
  P1 crystal_cluster (ground, 0.4-1.2 tall, glowing, light #8fa8ff or #c08fff, intensity 2),
     support_frame (wooden mine timber: two posts and a beam, blocking, 1 cell wide, ~1.6 tall),
     ore_cart (on its own, blocking, small), lantern (on a post, light #ffcf8a intensity 2)
  P2 rail_piece (straight track segment exactly 1 cell long, flat), crate, barrel

ruins (depths 15-16, buried temple; sandstone #9e8658-#b09660)
  P1 broken_column (blocking, 0.8-2.5 tall, fluted, broken top), column_base, rubble (flat
     pile of blocks), statue_head (big stone head half sunk, radius 0.45)
  P2 brazier (stone bowl with fire, light #ffb050 intensity 2), sarcophagus (blocking)

volcanic (depths 17-18; basalt #2e2420-#423a38, glowing cracks #ff5a1a)
  P1 basalt_columns (cluster of hexagonal columns of different heights, blocking, radius 0.45,
     flat tops so they read as steps), magma_rock (dark rock with glowing cracks, emissive
     part, light #ff6a20 intensity 1), ash_vent (small cone, sway 0)

abyss (depths 19-20; obsidian #22202a-#32303e, accents deep red / violet #3a1a3a)
  P1 obsidian_spike (ground, 1-2.5 tall, glossy-looking via colour), chain (ceiling, hanging
     chain 1-3 long, sway 0.2), bone_spire (bones and skulls piled into a spike)
  P2 rune_stone (dark slab with glowing red runes, light #ff3030 intensity 1), cage (hanging)

Nice to have (later, not now)
-----------------------------
* town props (well, market stalls, lamp posts, fences) for depth 0
* a few animated props (flickering flame, bubbling pool) - static is fine for now

Checking your work
------------------
* Open assets/props/<set>.glb in any glTF viewer: every prop is its own object, standing on the
  ground plane (or hanging from z = 0 for ceiling props), correct names, extras present.
* Rough size check: put the character (assets/character.glb, scaled 0.55) next to them.
